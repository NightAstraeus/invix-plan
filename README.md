# invix-plan — штаб ООО «Инвикс»

Создано: 03.10.2026.

Стратегия, цели, команда и партнёры предприятия по двум проектам — **ИНВИКС** (собственный крупноформатный 3D‑принтер) и **ТОФС** (заказчик, стенды компьютерного зрения). Репозиторий приватный, язык — русский.

Это слой **над** рабочими инструментами, не замена им:

| Что | Где живёт |
|---|---|
| Цели квартала и года, вехи | здесь — `strategy/` |
| Текущая картина и следующий шаг руководителя | здесь — `STATE.md` |
| Решения | здесь — `DECISIONS.md` |
| Вопросы владельцу, стратегические решения | Issues этой репы |
| Задачи команды | Telegram‑бот (`NightAstraeus/tg-work-bot`); здесь только зеркало `tasks/` |
| Железо принтера | `NightAstraeus/printer-config` (Issues, `PROJECT-STATE.md`) |
| Расчёт конструкции | `NightAstraeus/invix-cae` (`report/STRATEGY.md`) |
| Айдентика и материалы | `NightAstraeus/invix-brand` |

Чего здесь **нет** и не будет: финансов (суммы, цены, счета), текстов задач команды, технических заметок о принтере.

С чего начать: `STATE.md` → `strategy/GOALS-2026-Q4.md` → последний файл в `weekly/`. Правила для людей и агентов — `AGENTS.md`.

# Проект ИНВИКС — крупноформатный 3D‑принтер

Создано: 03.10.2026.

**Продукт.** Крупноформатный FDM‑принтер собственной разработки для литейной оснастки, прототипов и крупных деталей из термопластов. Экспериментальный образец: стол 690 × 960 мм, кинематика с ШВП по X и Y, портал на четырёх приводах Z, переделка в IDEX с двумя CAN‑тулхедами и сканером стола, Klipper. Факты для внешних материалов — только из `invix-brand/content/printer-brief.md`.

**Стадия (03.10.2026).** Первые печати получены на выставке 01–02.10.2026; качество не стабильно (смещения слоёв по X). Второй тулхед T1 не подключён. Закрытой термокамеры нет. Детали — `printer-config/PROJECT-STATE.md`.
